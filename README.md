### iterator とは？
反復子と呼ばれ、コンテナ内の各要素を参照するときの、**ポインターのようなもの**

### iterator の種類

1. != (比較演算子)で比較できること (first != last)
2. 間接参照演算子で要素を参照ｄけいること (*first)
3. インクリメント演算子で次の要素を指すこと (++first)
4. 間接参照演算子によって要素を書き換えられること
5. デクリメント演算子で1つ手前の要素を指すこと
6. 加算/減算演算子で整数値を足す/引くことで任意の数だけ進んだり戻ったりできること

1, 2, 3 		 を満たす  -> 入力イテレーター
1, 3, 4 		 を満たす　-> 出力イテレーター(output iterator)
1, 2, 3, 4	 　  を満たす  -> 順方向イテレーター(forward iterator)
1, 2, 3, 4, 5	 を満たす  -> 双方向イテレーター(biderectional iterator)
1, 2, 3, 4, 5, 6 を満たす  -> ランダムアクセスイテレーター(random access iterator)
